# کاوشگر کیهان — COSMOS EXPLORER

یک وب‌اپلیکیشن سه‌بعدی و موبایل‌اول برای دیدن زمین، ماه، خورشید و مریخ، و مشاهدهٔ موقعیت
واقعی اجرام در آسمان بر اساس مکان و زمان ناظر. این پروژه یک نسخهٔ آزمایشی (prototype) جدی
است، نه یک ادعای پوشش کامل کیهان یا جایگزین نرم‌افزار ناوبری نجومی.

## وضعیت کنونی

- نسخه: **۰٫۳٫۰**
- مرحله: کاوشگر قابل اجرا با هستهٔ علمی، زمین جغرافیاییِ پیوسته، روشنایی روز/شب UTC و
  رابط مکان فشرده؛ تست‌شده و مستند.
- نسخهٔ آنلاین:
  **[aryasamadi.github.io/cosmos-explorer](https://aryasamadi.github.io/cosmos-explorer/)**
  (وضعیت آخرین انتشار در [docs/deployment.md](docs/deployment.md) ثبت می‌شود.)
- مخزن: [github.com/Aryasamadi/cosmos-explorer](https://github.com/Aryasamadi/cosmos-explorer)
- نمایش پایه، محاسبات نجومی و مکان دستی به سرویس خارجی یا کلید دسترسی وابسته نیستند. برای
  جزئیات خیابانی زمین، کاشی‌های نقشهٔ OpenStreetMap فقط با نزدیک‌شدن دوربین و برای ناحیهٔ
  دیده‌شده بارگذاری می‌شوند.
- راهنمای انتشار در [docs/deployment.md](docs/deployment.md) آمده است.

## اکنون چه چیزهایی کار می‌کنند؟

### کاوش آزاد

- کرهٔ زمین سه‌بعدی با بافت محلی، جوّ نمایشی و ستارگان پس‌زمینه. کرهٔ پایه همیشه
  **کاملاً مات** است؛ کاشی‌های در حال بارگذاری یا ناموفق هرگز سوراخ یا شفافیت ایجاد
  نمی‌کنند.
- **روشنایی واقعی روز/شب:** نقطهٔ زیرخورشیدی از UTC و ephemeris محاسبه می‌شود؛ ترمیناتور
  با آن هم‌راستا است. سمت شب با چراغ‌های شهرهای NASA Black Marble روشن می‌ماند و این
  چراغ‌ها فقط در سمت شب نمایش داده می‌شوند.
- **موقعیت من روی زمین:** خواندن مکان واقعی دستگاه فقط با اجازهٔ کاربر یا ورود دستی
  مختصات، نمایش عرض/طول، منبع، شعاع دقت گزارش‌شده و دایرهٔ دقت روی کره. در صورت
  timeout/unavailable یک تلاش خودکار کم‌دقت (نه IP) انجام می‌شود و دقت واقعی گزارش
  می‌ماند.
- **جزئیات جغرافیایی واقعی:** با نزدیک‌شدن دوربین، کاشی‌های OpenStreetMap به‌صورت
  تدریجی برای کشورها، شهرها، خیابان‌ها و برچسب‌های واقعی بارگذاری می‌شوند. نمای پایه
  (قاره‌ها و اقیانوس‌ها) محلی است و به شبکه وابسته نیست.
- LOD محدود و کارآمد (حداکثر ۳×۳ کاشی در هر ناحیه)، درخواست‌های dedupe/محدود/لغوشده،
  کش هفت‌روزه و آزادسازی منابع.
- حساسیت چرخش و زوم بر اساس ارتفاع دوربین تنظیم می‌شود و حداقل فاصله، عبور از داخل
  زمین را مسدود می‌کند.
- ماه، خورشید و مریخ با متریال و رنگ متمایز.
- چرخش با لمس/ماوس، بزرگ‌نمایی با دو انگشت یا چرخ ماوس، و انتخاب جرم.
- حرکت نرم دوربین به سمت جرم انتخاب‌شده، نمای نزدیک زمین و دکمهٔ بازگشت به نمای کلی.
- پنل اطلاعات علمی شامل شعاع، جرم، فاصله، دورهٔ مداری و دما، همراه با نوع داده و منبع.
- نمایش صریح اینکه اندازه‌ها و فاصله‌های صحنه نمایشی و فشرده‌اند.

### آسمان واقعی

- دریافت موقعیت مکانی فقط با انتخاب کاربر؛ ورود دستی عرض و طول جغرافیایی نیز ممکن است.
- استفاده از زمان اکنون یا تاریخ و ساعت دلخواه (ورودی به وقت محلی، محاسبه بر پایهٔ UTC).
- محاسبهٔ موقعیت خورشید، ماه، مریخ و ۱۲ ستارهٔ درخشان با
  [Astronomy Engine](https://github.com/cosinekitty/astronomy) و تبدیل مستندشده به
  ارتفاع و سمت ناظر.
- نمایش گنبد آسمان با گرادیان روز/گرگ‌ومیش/شب، شبکهٔ ارتفاع و سمت و برچسب جهت‌های اصلی.
- نمایش وضعیت «بالای افق/زیر افق»، قدر ظاهری، درصد روشنایی ماه و فاصلهٔ لحظه‌ای در پنل.
- چرخش آزاد آسمان با لمس/ماوس و تغییر میدان دید.
- حسگر جهت‌یابی گوشی با درخواست اجازهٔ صریح، وضعیت‌های مشخص، کالیبراسیون دستی و
  بازگشت به چرخش آزاد در صورت نبود حسگر یا ردشدن اجازه.
- لایهٔ اختیاری تصویر دوربین پشت گوشی با اجازهٔ جداگانه؛ توقف کامل جریان دوربین هنگام خروج.
- ارسال‌نشدن تصویر دوربین یا دادهٔ حسگر به هیچ سرور یا سرویس تحلیلی. برای جزئیات نقشه،
  فقط درخواست کاشی‌های ناحیهٔ دیده‌شده به OSM فرستاده می‌شود (نه مختصات دقیق دستگاه).

## اجرای محلی

نسخهٔ منتشرشده روی GitHub Pages از HTTPS استفاده می‌کند و برای آزمایش مجوزهای گوشی مناسب
است. برای توسعهٔ محلی:

پیش‌نیاز: Node.js نسخهٔ ۲۲٫۱۲ یا جدیدتر و npm.

```bash
npm install
npm run dev
```

سپس `http://localhost:5173` را باز کنید.

اسکریپت‌های پروژه:

```bash
npm run dev        # اجرای محلی
npm run build      # بررسی نوع‌ها + ساخت نسخهٔ production
npm run preview    # پیش‌نمایش build
npm run lint       # بررسی کیفیت کد
npm run typecheck  # بررسی نوع‌ها
npm run test:ci    # اجرای همهٔ تست‌های Vitest یک بار
npm run test:e2e   # تست مرورگری موبایل با Playwright و Chrome نصب‌شده
npm run check:pages # بررسی مسیر دارایی‌ها در dist (پس از build)
```

## آزمون روی گوشی

1. رایانه و گوشی را به یک شبکهٔ Wi‑Fi وصل کنید.
2. اجرا کنید:

   ```bash
   npm run dev -- --host 0.0.0.0
   ```

3. آدرس شبکهٔ محلی نمایش‌داده‌شده (مثلاً `http://192.168.1.10:5173`) را در مرورگر گوشی باز کنید.

> **مهم:** بیشتر مرورگرها دسترسی به موقعیت دقیق، دوربین و حسگر جهت‌یابی را فقط در
> «بستر امن» (HTTPS یا localhost) می‌دهند. باز کردن آدرس `http` روی شبکهٔ محلی معمولاً برای
> ورود دستی مختصات و چرخش آزاد کافی است، اما برای آزمایش واقعی مجوزهای حسگر و دوربین باید
> نسخهٔ HTTPS (مثلاً GitHub Pages) را استفاده کنید.

## مجوزها و حریم خصوصی

- موقعیت مکانی فقط پس از کلیک روی دکمهٔ دریافت موقعیت درخواست می‌شود. اگر اجازه رد شود،
  برنامه از کار نمی‌افتد و ورود دستی مختصات باقی می‌ماند.
- اجازهٔ حسگر و دوربین جداگانه و فقط با اقدام کاربر درخواست می‌شود.
- مختصات و دادهٔ حسگر/دوربین ذخیره یا مستقیماً ارسال نمی‌شوند؛ فقط در حافظهٔ همان زبانه
  برای محاسبه و نمایش محلی استفاده می‌شوند.
- با نزدیک‌شدن دوربین به زمین، مرورگر کاشی‌های دیده‌شده را از سرورهای OpenStreetMap
  دریافت می‌کند. این درخواست‌ها برای آن سرویس مشخص می‌کند محدودهٔ تقریبی نمای فعلی
  چیست؛ جزئیات در برگهٔ مکان و [سند انتساب](docs/attribution.md) آمده است.
- کاشی‌های دیده‌شده حداکثر هفت روز در Cache Storage مرورگر کش می‌شوند؛ نقشه برای آفلاین
  استفاده یا prefetch دانلود نمی‌شود.
- جریان دوربین هنگام خاموش‌کردن یا خروج از صفحه متوقف و trackهای آن آزاد می‌شوند.
- تحلیل‌گر (analytics)، حساب کاربری، دیتابیس یا backend وجود ندارد.

## محدودیت‌های شناخته‌شده

- این نسخه کل منظومهٔ شمسی یا همهٔ سیارات را ندارد؛ فقط زمین، ماه، خورشید، مریخ و ۱۲ ستارهٔ
  درخشان به‌همراه موقعیت‌های محاسباتی آن‌ها ارائه می‌شوند.
- در «کاوش آزاد»، مکان و اندازهٔ اجرام نمایشی و فشرده است. جای زمین/ماه/مریخ در آن صحنه
  موقعیت نجومی واقعی نیست؛ فقط اطلاعات عددی پنل علمی است.
- در «آسمان واقعی»، ارتفاع هندسی محاسبه می‌شود و شکست نور جوّ، افق محلی، ساختمان‌ها، ابرها و
  وضعیت دید آسمان لحاظ نمی‌شود.
- جای ستارگان با مختصات J2000 و بدون حرکت خاص محاسبه می‌شود. کاتالوگ ستارگان کامل نیست.
- دقت حسگر جهت‌یابی به دستگاه، مرورگر، قطب‌نما و جهت صفحه وابسته است. در محیط توسعهٔ این
  پروژه روی گوشی واقعی آزمایش نشده است. مرجع شمال حقیقی در همهٔ دستگاه‌ها تضمین نمی‌شود و
  کالیبراسیون دستی برای همین حالت وجود دارد.
- لایهٔ دوربین یک هم‌ترازی تقریبی مبتنی بر حسگر و تصویر است، نه AR دقیق و نه هم‌سطح
  ARKit/ARCore. میدان دید دوربین از مرورگر قابل خواندن نیست و به‌صورت دستی تنظیم می‌شود.
- اجرام آسمانی با نشانه‌های گرافیکی ساده نمایش داده می‌شوند؛ این نشانه‌ها تصویر واقعی تلسکوپی
  یا اندازهٔ زاویه‌ای واقعی نیستند.
- روشنایی زمین یک نمایش آموزشی است، نه رادیانس فیزیکی یا تصویر هواشناسی لحظه‌ای: ابرها،
  جوّ واقعی، آلودگی نوری و فصل تغییر چراغ‌ها لحاظ نمی‌شوند. چراغ‌های شهر از مجموعهٔ
  ثابت NASA Black Marble سال ۲۰۱۲ هستند. ترمیناتور به ساعت UTC دستگاه وابسته است؛ ساعت
  اشتباه دستگاه، روشنایی را جابه‌جا می‌کند.
- جزئیات محلی زمین از نقشهٔ کارتوگرافی OpenStreetMap می‌آید، نه تصویر ماهواره‌ای؛
  کامل بودن خیابان‌ها و نام‌ها در همهٔ مناطق تضمین نمی‌شود.
- حداکثر جزئیات نقشه در این نسخه در حدود سطح z14 (نقشهٔ محلی/خیابان‌ها) است. منبع OSM تا
  z19 پشتیبانی می‌کند، اما محدودیت عمدی اندازهٔ شبکهٔ کاشی و ارتفاع دوربین بالاتر نمی‌رود.
- نقشهٔ OSM در عرض‌های بالاتر از ±۸۵٫۰۵ درجه وجود ندارد؛ در قطب‌ها بافت پایه دیده می‌شود.
- دقت مکان مرورگر تضمین GPS نیست. عدد «شعاع دقت» همان مقدار گزارش‌شدهٔ دستگاه و آماری
  است، نه مرز قطعی مکان. دقت روی گوشی واقعی صحت‌سنجی نشده است.
- هیچ benchmark رسمی عملکرد روی گوشی انجام نشده است؛ اندازهٔ بسته و دارایی‌ها در build ثبت
  می‌شود، اما نرخ فریم و مصرف باتری در همهٔ دستگاه‌ها اندازه‌گیری نشده است.

## تست و کنترل کیفیت

```bash
npm run lint
npm run typecheck
npm run test:ci
npm run build
```

- ۱۳۶ تست Vitest در حوزه‌های مختصات نجومی و جغرافیایی، ephemeris، نقطهٔ زیرخورشیدی،
  WGS84، ریاضیات کاشی و LOD، حساسیت دوربین و برخورد، اعتبارسنجی مکان، مجوزها، کاتالوگ،
  حسگرها، پنل اطلاعات، جریان‌های UI و آزادسازی منابع وجود دارد.
- چهار تست مرورگری Playwright در viewport موبایل ۳۹۰×۸۴۴ جریان انتخاب جرم، ورود دستی و
  دستگاه مکان، **رفتار شکست کاشی‌ها** و **مات‌ماندن کرهٔ روز زیر بارگذاری/شکست کاشی و
  زوم نزدیک** را در Chrome واقعی اجرا می‌کنند. درخواست‌های OSM در تست‌ها عمداً مسدود
  می‌شوند تا به سرویس بیرونی وابستگی یا بار غیرمجاز وارد نشود.
- محاسبات با نمونه‌های مستقل JPL Horizons مقایسه می‌شوند. جزئیات و تلورانس‌ها در
  [docs/testing.md](docs/testing.md) آمده است.
- رابط کاربری در Headless Chrome با viewport موبایل ۳۹۰×۸۴۴ و سناریوهای حسگر و دوربین
  شبیه‌سازی‌شده نیز بررسی شده است. آزمون سخت‌افزاری روی گوشی واقعی هنوز انجام نشده است.

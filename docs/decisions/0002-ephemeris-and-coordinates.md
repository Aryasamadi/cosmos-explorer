# ADR 0002 — Astronomy Engine و تبدیل مختصات مستقل

- وضعیت: پذیرفته‌شده
- تاریخ: ۲۰۲۶-۱۰-۲۲

## زمینه

موقعیت ماه، خورشید و سیارات نباید از ابتدا اختراع شود. در عین حال رابط باید مستقل از
کتابخانه بماند و قرارداد آزیموت/ارتفاع قابل تست و مستند باشد.

## تصمیم

- از `astronomy-engine` 2.1.19 (MIT) برای ephemeris استفاده می‌شود.
- مختصات استوایی تاریخ با `Equator(..., ofdate=true, aberration=true)` گرفته می‌شود.
- تبدیل به ارتفاع/سمت با پیاده‌سازی داخلی `equatorialToHorizontal` انجام می‌شود؛ این
  پیاده‌سازی به‌طور مستقل تست شده و با `Horizon` همان کتابخانه و JPL Horizons مقایسه
  شده است.
- شکست نور جو عمداً اعمال نمی‌شود؛ خروجی «ارتفاع هندسی» نامیده می‌شود.
- ستارگان J2000 با ماتریس پیش‌روی کتابخانه به تاریخ منتقل می‌شوند، اما حرکت خاص و
  پارالاکس سالانه ندارند.

## دلیل

- محاسبات پیچیده و حساس، مرجع معتبر دارند.
- نگه‌داشتن تبدیل افقی در کد خودمان، قرارداد را صریح و قابل آزمون می‌کند و وابستگی
  UI به API کتابخانه را کم می‌کند.
- حذف شکست جو، تست را با مرجع airless ساده و قابل دفاع می‌کند.

## پیامدها

- نتایج نزدیک افق با نمای چشم غیرمسلح کمی تفاوت دارند؛ این محدودیت در UI و مستندات
  ذکر شده است.
- اگر در آینده شکست جو لازم شود، باید به‌صورت یک گزینهٔ صریح و با تست‌های جداگانه
  اضافه شود.
- دقت ادعاشده فقط در نمونه‌های مستند JPL سنجیده شده است.

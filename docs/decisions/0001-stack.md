# ADR 0001 — پشتهٔ فنی: React، Vite، TypeScript و Three.js

- وضعیت: پذیرفته‌شده
- تاریخ: ۲۰۲۶-۱۰-۲۲

## زمینه

هدف، یک وب‌اپ استاتیک موبایل‌اول با صحنهٔ سه‌بعدی، محاسبات نجومی قابل تست و انتشار
رایگان روی GitHub Pages است. مخزن در شروع خالی بود.

## تصمیم

- **TypeScript strict** برای قراردادهای مختصات و جلوگیری از NaN/undefined در مسیرهای
  علمی.
- **React** برای رابط کاربری متمرکز و قابل تست.
- **Vite** برای dev server سریع، build استاتیک و پشتیبانی از base path قابل تنظیم.
- **Three.js** به‌عنوان موتور سه‌بعدی، چون بالغ، سبک‌تر از موتورهای بومی و مناسب وب است.
- **Vitest + Testing Library** برای تست‌های سریع بدون نیاز به مرورگر در CI.
- **Playwright** برای یک smoke test واقعی مرورگری در viewport موبایل؛ از Chrome نصب‌شده
  روی runner استفاده می‌کند و مرورگر جداگانه دانلود نمی‌شود.
- **npm + package-lock.json** برای نصب تکرارپذیر.

## دلیل رد گزینه‌های دیگر

- Unreal/Unity WebGL: پیچیدگی و حجم غیرضروری برای یک نمایش سیاره‌ای سبک.
- WebGPU: سازگاری دستگاه‌ها و ریسک بالاتر برای نسخهٔ اول.
- Next.js/SSR: نیاز واقعی به سرور یا SEO ندارد؛ خروجی استاتیک Vite کافی است.
- کتابخانهٔ UI سنگین: رابط کوچک است و استایل دستی، کنترل RTL و حجم کمتری می‌دهد.

## پیامدها

- بستهٔ Three.js بزرگ‌ترین بخش JS است و به‌صورت chunk جداگانه بارگذاری می‌شود.
- UI به‌صورت SPA است و deep-link ندارد؛ بنابراین برای Pages به fallback سمت سرور
  نیاز نیست.
- ارتقای نسخه‌های اصلی Vite/React نیازمند بررسی سازگاری با Node و eslint است.

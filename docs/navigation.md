# ناوبری کاوش آزاد

## ماوس

- کشیدن با دکمهٔ چپ: چرخش دوربین حول مرکز فعلی.
- کشیدن با دکمهٔ راست: جابه‌جایی (Pan) صحنه.
- چرخ ماوس: زوم نرم؛ حساسیت نزدیک سطح زمین کاهش می‌یابد.

## لمس

- یک انگشت: چرخش.
- دو انگشت: pinch برای زوم و جابه‌جایی هم‌زمان (رفتار OrbitControls).
- دکمهٔ «نمای کلی» همیشه دوربین را به نمای اولیه برمی‌گرداند.

## صفحه‌کلید

| کلید | عمل |
| --- | --- |
| `←` `→` `↑` `↓` | چرخش دوربین |
| `Shift + جهت` | جابه‌جایی صحنه |
| `+` / `-` | زوم |
| `Home` یا `0` | بازگشت به نمای کلی |
| `1` / `2` / `3` / `4` | انتخاب زمین / ماه / خورشید / مریخ |

میانبرها فقط وقتی «کاوش آزاد» فعال و focus روی ورودی، slider یا dialog نیست
اجرا می‌شوند. همین راهنما در «تنظیمات و منابع» نیز نمایش داده می‌شود.

## حفظ وضعیت

- انتخاب جرم در هر حالت جدا نگه داشته می‌شود؛ ورود به Sky و بازگشت به Free
  انتخاب قبلی Free را برمی‌گرداند.
- صحنهٔ Free هنگام رفتن به Sky فقط pause می‌شود و dispose نمی‌شود؛ camera pose،
  location، map state و انتخاب حفظ می‌شوند.
- برای هر جرم آخرین pose دوربین ذخیره می‌شود. مسیر `Earth → Moon → Earth` نمای
  نزدیک Earth را برمی‌گرداند، نه overview.
- دکمهٔ «نمای کلی» آگاهانه pose ذخیره‌شدهٔ Earth را به overview بازنشانی می‌کند.

## محدودیت‌ها

- ناوبری آزاد در این نسخه حول یک target (Earth یا جرم انتخاب‌شده) orbit/pan
  می‌کند و 6DOF کامل یا پرواز آزاد بدون target نیست.
- دقت علمی و مقیاس‌های نمایشی تغییری نکرده‌اند.
